处理流程

从画面到告警的五步闭环

视频采集 → 人员 / 姿态 / PPE 检测 → 风险规则判断 → 持续时间与运动量确认 → 语音预警与事件留档

01

视频采集

  1. USB / 内置 / RTSP / 视频文件
  2. 断流检测 + 自动重连
  3. 按工位归一化坐标
02

检测 + 跟踪

  1. YOLO Pose 17 关键点
  2. ByteTrack 跨帧 ID
  3. 独立 PPE 模型（按帧间隔异步）
03

规则判断

  1. 6 类风险：bend / fall / zone / helmet / drowsy / unconscious
  2. 二维投影几何（多边形 + 角度）
  3. 运动量比较防误报
04

去抖确认

  1. 持续时长门控（duration_seconds）
  2. 同类告警冷却（cooldown_seconds）
  3. 跟踪丢失复位（expire_tracks）
05

语音 + 留档

  1. macOS say / Linux espeak / Windows SAPI
  2. 队列化异步播报
  3. SQLite + 可选告警截图
规则引擎

开箱即用的 6 类风险规则

每条规则独立配置阈值 / 持续时长 / 冷却时间 / 严重等级，可由安全员现场校准。

⚠未佩戴安全头盔

检测到人员头部但未在头部附近找到安全帽；或 PPE 模型直接输出 no_helmet 标签。持续 2 秒触发告警，冷却 12 秒。

⤵过度弯腰

躯干轴相对竖直方向夹角 ≥ 42° 持续 1.5 秒，触发搬运姿势告警，提示屈膝并保持背部挺直。

↓疑似跌倒

躯干角度 ≥ 62° 且人员框宽高比 ≥ 1.15 持续 0.8 秒，触发 critical 级告警，提示立即检查。

☕疑似睡着

头部下垂且躯干运动量持续低于阈值 12 秒，触发高风险告警，提醒安全员确认人员状态。

＋疑似晕倒

倒地 + 持续低运动量 3 秒升级为 critical 级告警，提示立即救援；同时向事件中心推送。

⛔进入危险区域

手腕或脚踝关键点进入现场危险区域多边形 0.35 秒，触发撤离提醒，冷却 6 秒。

识别引擎

两个模型，三层去抖

YOLO Pose 提供 17 关键点，独立 PPE 模型按帧间隔异步加载；规则引擎持续时长 + 同类冷却 + 跟踪丢失复位三层去抖。

Ultralytics YOLO Pose

COCO 17 关键点格式 + ByteTrack 跨帧 ID，单帧推理延迟通常 < 30ms（GPU）/ < 80ms（CPU）。

03

6 类规则引擎

几何 + 运动量双重判定，每条规则独立 duration / cooldown 配置，杜绝瞬时误报。

04

队列化语音播报

macOS say / Linux espeak / Windows PowerShell SAPI 自动 fallback，后台线程异步播放不阻塞检测循环。

部署特性

离线优先 · 隐私默认

整套系统本地推理，原始视频默认不长期保存；只有脱敏后的事件进 SQLite 数据库，可按需配置截图策略。

✓本地推理

YOLO Pose + PPE 模型全部在用户电脑或厂区边缘盒子上运行，不需要上传任何画面到云端。

✓事件留档

SQLite 记录工位 / 时间 / 跟踪编号 / 风险类型 / 持续时长，可由 /api/events 查询与确认。

✓配置驱动

所有阈值、区域、时长、冷却时间均在 config/default.json 中声明，部署新工位只需改 JSON。

✓快照可选

alerts.save_snapshots 默认开启，仅在告警触发瞬间保存带叠加层的画面供安全员复核。
