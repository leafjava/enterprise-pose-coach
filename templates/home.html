AGENT ORCHESTRATION · SINGLE SKILL LIFECYCLE

ClawHive Agent 调用一个 Skill：从首次训练到后续持续复用

01

HR 发起首次调用（训练）

"为新工厂 A 训练深蹲 50 次招聘能力，使用近 3 个月脱敏样本"——HR 在飞书 / 钉钉 / 企微 / OA 里直接发起，best_weight_id 不填。

02

Skill 内部训练 + 沉淀

Skill 指导 Agent 完成数据获取 → 数据处理（清洗 / 关键点 / 48 帧切窗 / 划分）→ 模型训练 → 效果评估 → 选择 Best 权重 → 沉淀到企业私有环境，输出 best_weight_id。

03

Skill 后续调用：直接复用

HR 发起"今天 A 批候选人创建深蹲 50 次检测"，Agent 调用 enterprise-pose-coach 并传入 best_weight_id——候选人摄像头前完成动作，Skill 直接加载 Best 权重进入毫秒级实时监测 + 即时语音纠错 + 完整周期计数。

04

结构化回写 + 持续进化

汇总 pass / not_met / needs_retraining / inconclusive，连同 best_weight_id / best_weight_version、规则版本、Top 错误一并回写招聘台账，需复核项通知 HR；后续积累新样本可再训练升级，旧版本可回滚。
