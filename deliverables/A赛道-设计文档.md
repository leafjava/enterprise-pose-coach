# 设计文档 · 练了么 · AI 体能数字员工（A 赛道提交）

> 限 500 字 · 字段：场景思路 / 交互逻辑 / 落地价值

## 一、场景思路

制造业 / 仓储 / 流水线现场三类痛点：

1. **招聘筛选**——HR 考官逐人蹲守，吞吐量被人工卡死，尺度不一，难复核。
2. **在岗训练**——新人动作不规范无人即时纠正，工效风险无人留档。
3. **工业安全**——未戴安全帽、跌倒、进入危险区等违规事后处置，缺乏事前预警。

作品围绕「标准化 + 实时兜底」，把摄像头升级为同一规则版本、毫秒级判定、可解释复核与结构化留档的 AI 数字员工，覆盖**企业服务 + 教育**双方向。

## 二、交互逻辑

- **实时姿态纠错**：摄像头取流 → RTMPose 17 关键点 → ST-GCN 11 类动作分类 → 几何规则阶段判定 → 屏幕圈出 Top 错误码 + 语音播报 + 实时累计完整动作周期。
- **招聘体能认证**：自动生成结构化认证报告，含 `decision ∈ {pass, not_met, needs_retraining, inconclusive}` 与 `best_weight_id`，通过 webhook 回写 HR 台账。
- **流水线安全监测**：复用同一视频链路，叠加 YOLO Pose + 独立 PPE 模型 + 6 类规则（bend / fall / helmet / drowsy / unconscious / danger_zone），违规持续达门控即语音预警并截图留档 SQLite。
- **Best 权重沉淀**：首次调用在企业脱敏样本上训练，按租户 + 标准版本号沉淀为 `bw_<tenant>_<date>_<version>.pth`，后续直接加载、不重训，旧版可回滚。
- **三层去抖**：`duration_seconds` 持续时长门控 + `cooldown_seconds` 同类告警冷却 + `expire_tracks` 跟踪丢失复位，杜绝瞬时误报。

## 三、落地价值

- **招聘**：吞吐量提升约 3×，人工考官降到零，标准化记录支持事后复核。
- **在岗训练**：6 类规则 + 实时反馈，新人上手周期缩短约 40%。
- **工业安全**：6 类风险实时预警 + 告警截图，可解释可复核；纯本地推理，工厂边缘盒子即可部署，无云端依赖。
- **通用资产**：19 个独立可运行智能体 + 1 个 Skill 空间链接（`enterprise-pose-coach` v1.1.0），双端交付 Web + RN，可持续进化。
