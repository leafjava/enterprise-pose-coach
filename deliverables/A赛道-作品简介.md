# 作品简介 · 练了么 · AI 体能数字员工（A 赛道提交）

> 限 200 字 · 字段：场景 / 核心能力 / 创新点

**场景**：制造业 / 仓储 / 流水线现场，把 HR 考官与安全员升级为标准化、可解释、可留档的 AI 数字员工，覆盖招聘、在岗训练、工业安全三段链路。

**核心能力**：RTMPose 17 关键点 + ST-GCN 11 类动作驱动实时姿态纠错与自动计数；独立 PPE 模型 + 6 类规则（bend / fall / helmet / drowsy / unconscious / danger_zone）驱动流水线语音预警与告警留档；Best 权重按租户版本号沉淀复用。

**创新点**：「训练 + 沉淀 + 复用」机制，权重按租户隔离沉淀、旧版可回滚；配合三层去抖（持续时长 + 冷却 + 跟踪复位）杜绝瞬时误报；纯本地推理，工厂边缘盒子即可部署。
